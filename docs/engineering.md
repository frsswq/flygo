# Engineering notes

## Repository layout

```text
src/flygo/            Python package: data pipeline, rules, dynamics, FastAPI
web/                  React app: rules engine, browser dynamics, canvas board
web/public/flygo/     Committed browser bundle, written by export-web
shared/               Conformance fixtures replayed by both languages
docs/                 Experiment protocol, deployment notes, and data profile
tests/                Python tests
```

Production Python code uses Polars instead of pandas.
PyArrow exists only as a compatibility boundary for one nullable dictionary column in the official annotation Feather file.

## Browser bundle

The viewer loads the frozen graph and the policy in the browser, so the binaries are committed under `web/public/flygo/`:

```bash
uv run flygo export-web
```

`src/flygo/export.py` documents every byte offset.
The manifest records the layout, the dynamics constants, and a SHA-256 for each file.
A 9x9 visit downloads about 470 KB: `graph.bin` plus `policy-9.bin`.

## Conformance fixtures

Both rule engines and the browser dynamics are checked against shared fixtures:

```bash
uv run flygo conformance
uv run flygo policy-conformance
```

| Fixture | Generated by | Replayed by |
| --- | --- | --- |
| `shared/rules-conformance.json` | `flygo conformance` | `tests/test_conformance.py` and `web/src/lib/go-rules.test.ts` |
| `shared/policy-conformance.json` | `flygo policy-conformance` | `web/src/lib/policy.test.ts` |

Regenerate a fixture after changing either engine, and never edit a fixture by hand.
The policy test also verifies the recorded hashes, so it fails when the binaries and the fixture disagree.

## Checks

`make check` runs every check.
The individual commands are:

```bash
uv run ruff format --check .
uv run ruff check .
uv run vulture
uv run basedpyright
uv run pytest
cd web && npm run check && npm run typecheck && npm run knip && npm test
```

Dead code is gated per language.
`uv run vulture` covers Python at a confidence of 60, because vulture assigns that confidence to unused functions, methods, and classes while its default of 80 would hide them.
`[tool.vulture]` in `pyproject.toml` lists the names that pydantic calls at runtime or that belong to the documented response schema and the planned baseline surface.
`npm run knip` covers unused exports, unused files, and unused dependencies in the web app, and `web/knip.json` exempts the vendored shadcn component API in `src/components/ui`.
Both commands exit non-zero when they find something.

Vite proxies `/api` requests to port 8000 for API work.
